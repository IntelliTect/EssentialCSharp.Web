## Page metadata

The shared layout uses `ViewData["Description"]` for the HTML, Open Graph, and Twitter descriptions; pages without an override use the site-wide fallback. Public page actions set their own descriptions. Chapter pages use `Chapters/sitemap.descriptions.json` when available (generated by ParserCli), or a description based on the chapter heading when the file is absent. Views can also set `ViewData["Description"]` before the layout renders.

Parser-generated chapter HTML supplies its canonical link; other public pages get a canonical link from the layout. Open Graph URLs follow the canonical URL, with `SiteSettings:BaseUrl` and the request path used when no chapter canonical is available. Query strings are excluded.
